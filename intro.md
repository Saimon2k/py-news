# PyNews Digest Bot

PyNews Digest Bot — Telegram-бот для сбора публикаций из выбранных каналов и подготовки новостных дайджестов. Для анализа текстов используется локальная языковая модель Ollama.

## Как это работает

Пользователь добавляет Telegram-каналы в свой список. Бот собирает новые публикации, обрабатывает их с помощью модели и формирует очередь коротких новостных заметок с указанием источников. Затем пользователь получает подготовленные новости по одной.

Для чтения каналов используется авторизованный пользовательский аккаунт Telegram, а для общения с пользователем — отдельный бот.

## Основные возможности

- Добавление, просмотр и удаление каналов-источников.
- Сбор новых публикаций с учётом времени предыдущего сбора.
- Обработка публикаций моделью: фильтрация рекламы и подозрительных сообщений, группировка новостей об одном событии и создание кратких резюме.
- Выдача новостей по одной с указанием источников.
- Хранение списка каналов и очереди дайджеста в базе SQLite.

Если модель не возвращает подходящие новости, применяется запасной вариант с последними публикациями. Совпадающие публикации помечаются как дубликаты, но не удаляются из набора перед анализом.
